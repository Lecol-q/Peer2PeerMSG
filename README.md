# Java Peer to Peer Terminal Messaging
Very simple terminal peer to peer messaging program for java.

## Description
Uses java net package. Programs a socket and server socket to communicate.

## Getting Started
1. Download TerminalMsgJava folder
2. if you are on MacOS run MsgJava.command. If you are on Windows run MsgJava.bat

Once the program starts running in the terminal follow the prompts

1. Enter a name
2. Both users must enter the same IP, if you are the user creating the connection please insert your IP, then the person joining will enter your IP to join the connection
3. Enter a port. Default port 12345
4. If you are host of the IP enter 1 to start connection, if you are the peer joining enter 2 to join connection

From there you should be connected and can send string inputs to each other through the terminal
